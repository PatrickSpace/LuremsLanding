# Plantilla de tarea o encargo

Ayuda opcional: elimina lo que no aplique. Puede completarse en un mensaje. **Nombrar aquí un rol destinatario no selecciona ni cambia el rol activo del chat, ni autoriza crear o contactar otro.**

- **Rol destinatario:** una especialidad responsable de este encargo.
- **Objetivo, problema y público:** qué debe resolverse y para quién.
- **Sistema y entorno:** web pública o app; repositorio, dominio o versión cuando sean relevantes.
- **Fuentes:** enlaces a contexto, evidencia, especificación, diseño o entrega previa pertinentes.
- **Decisiones y autorizaciones vigentes:** qué aprobó el usuario y dónde consta. Distinguirlo de recomendaciones.
- **Alcance y exclusiones:** qué parte corresponde a este rol y qué queda fuera.
- **Entregable esperado:** documento, diseño, implementación o verificación, según el rol.
- **Criterios de aceptación:** resultados observables; incluir estados, dispositivos, accesibilidad o SEO si aplican.
- **Dependencias y decisiones pendientes:** identificar responsable; avanzar en lo independiente sin inventar respuestas.
- **Verificación esperada:** entorno, método y evidencia proporcional; indicar si requiere comprobación sobre la web publicada.
- **Brand System:** reglas y componentes afectados o motivo de ausencia de impacto visual.

Incluir restricciones de privacidad, costos o publicación solo cuando sean pertinentes. Este encargo no concede aprobaciones o autorizaciones por el mero hecho de rellenar la plantilla.
